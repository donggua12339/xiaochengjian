## 一、项目概述

### 1.1 定位

小城笺 (XiaoChengJian) 是面向独立开发者的**私有应用攻防与遗产维护平台**，采用开源 + SaaS 双模式运营。核心价值主张：

- **卡密验证** — 保护应用商业授权
- **APK 加固** — 抵御逆向/篡改/脱壳/注入
- **安全审计** — 自有 APK 合规诊断

### 1.2 产品线

| 产品线             | 定位             | 功能范围                     |   定价    |
| ------------------ | ---------------- | ---------------------------- | :-------: |
| **玄甲 (XuanJia)** | 开源免费加固 SDK | X0-X9 全量防护(门禁+陷阱)    |   免费    |
| **天衍 (TianYan)** | 付费高级加固引擎 | T1-T6 在玄甲基础上叠加迷宫层 |   付费    |
| **卡密系统**       | SaaS 授权验证    | 生成/验证/设备绑定/批量/2FA  | 免费+增值 |

### 1.3 合规框架

- **纯防守向**: 禁止通用脱壳/去签/重打包他人 APK
- **七锁架构**: 对象/内容/入口/签名/权限/数据/客户端签名自检
- **99 个 ADR**: 所有重大决策均有架构决策记录追溯
- **律师闭环**: ADR 0077-0097 经法律合规审查

### 3.5 攻击成本提升 7 项 — ✅

| 手段              | 效果                                       |
| ----------------- | ------------------------------------------ |
| Canary 防短路     | hook return 0 不更新 canary → 识破         |
| Honeypot 诱饵     | 假密钥/URL/RSA 浪费攻击者数小时            |
| 白盒 S-box        | XOR key 熔入 16×256 查找表, .rodata 无密钥 |
| cache-timing 对抗 | prefetch 全 256 entry 抹平访问模式         |
| VM 行为自检       | 字节码头部 MOV→COPY→XOR→验零, patch 即暴露 |
| opcode XOR 洗牌   | 每构建随机 key, IDA 每次看到不同字节       |
| ELF 假 magic      | cl 加载后写 \x7fPRV, 匿名页扫描定位失败    |
