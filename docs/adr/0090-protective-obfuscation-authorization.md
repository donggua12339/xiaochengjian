# ADR 0090: 保护性混淆授权(DEX 字符串加密及加固技术合规边界)

- **状态**: accepted
- **日期**: 2026-07-26
- **决策者**: 用户 + 项目法律顾问
- **关联**: ADR 0077(SDK 注入红线), ADR 0091(玄甲/天衍产品线), PRODUCT_XUANJIA_TIANYAN.md §5/§6

## 背景

天衍 T4(DEX 字符串加密)与玄甲 v1.1 X14 需要修改用户 APK 的 DEX 字节码
(baksmali → 替换 const-string → 插入 native 解密调用 → smali 回编)。
此能力与 ADR 0077"禁止字节码修改"存在表面张力,需律师明确授权边界。

2026-07-26 项目法律顾问出具正式法律意见书,结论:
**DEX 字符串加密等防守加固技术,在保护自有 APK 著作权的合法目的下,依法可以做。**

## 法律依据(摘要)

1. **《著作权法》(2020 修订) §49/§53**:技术措施受法律保护。字符串加密、
   DEX 加固、完整性校验属于"为保护软件著作权而采取的技术措施"。
2. **《刑法》§217 第(六)项**:故意避开或破坏著作权技术措施,情节严重构成犯罪。
3. **上海知识产权法院判例**(精雕诉奈凯):技术措施须以"保护著作权"为目的,
   不得用于捆绑销售/限制兼容性/排斥竞争。
4. **《密码法》**:鼓励依法使用商用密码;优先国密算法(SM2/SM3/SM4)。
5. **美国 EAR**:高强度加密软件出海需评估 ECCN 分类;开源享有 §742.15(b) 豁免。

## 决策

### 授权范围

以下技术措施,在保护自有 APK 著作权及与著作权有关的权利的目的下,**授权实施**:

| 技术 | 法律定性 | 归属 |
|------|---------|------|
| DEX 字符串加密(const-string → 加密 byte[] + native 解密) | 著作权技术措施 | 天衍 T4 / 玄甲 v1.1 |
| DEX 方法抽取/加密 | 著作权技术措施 | 天衍 v1.1 |
| SO 文件加密 + 自实现 Linker | 著作权技术措施 | 玄甲 X0 / 天衍 T1 |
| VMP 虚拟机保护 | 著作权技术措施 | 天衍 T2 |
| 签名校验 / 完整性校验 | 著作权技术措施 | 玄甲方案 A/B/C |
| 防调试 / 防注入 / 防 dump | 著作权技术措施 | 玄甲 X4 |
| 运行时环境检测(Root/Xposed/Frida) | 著作权技术措施 | 玄甲 X4 |
| 检测到技术措施被规避时终止自有 APK 进程 | 技术措施正常行使 | 玄甲/天衍 |

### 法律约束(五条)

1. **目的约束**:所有技术措施仅用于保护本项目 APK 的著作权及与著作权有关的权利,
   不得用于捆绑销售、限制兼容性、排斥竞争。
2. **对象约束**:技术措施仅作用于自有 APK 进程,不得影响设备其他应用或系统组件。
3. **算法约束**:优先使用国密算法(SM2/SM3/SM4);若使用境外加密算法需评估出口管制。
4. **响应约束**:kill 响应仅终止被保护 APK 自身进程,不附加数据破坏或隐私窃取。
5. **出海约束**:上架 Google Play 时遵守动态代码加载政策,提交 mapping.txt。

### 禁止行为(红线)

1. **禁止检测并杀伤特定逆向工具进程**(MT/NP/Frida 等作为独立目标)。
   允许的是:检测自有 APK 进程是否被注入/调试/重签,无论工具是什么。
2. **禁止借防护之名窃取用户隐私或破坏用户数据**。
3. **禁止将技术措施用于垄断或不正当竞争目的**。
4. **禁止使用未经合规评估的高强度加密算法出海分发**。

### T4 实施约束(DEX 字符串加密专项)

- 修改范围**仅限** `const-string` 指令替换为加密 byte[] + native 解密调用
- **不改业务逻辑**、不插入广告、不修改控制流
- 用户必须**主动选择**启用(Packer `--encrypt-strings` 显式开关)
- 解密 native 函数由 SDK 提供,不引入第三方代码
- 加密后 APK 仍使用**开发者自备 Keystore** 重签(V1+V2+V3)

## 与 ADR 0077 的关系

ADR 0077 禁止"字节码修改/重打包**他人** APK"。本 ADR 授权的是:
- 对**开发者自有、有合法著作权的 APK** 实施保护性混淆
- 经开发者**主动选择**启用
- 目的限于**保护著作权**

两者不矛盾:0077 禁止的是进攻性/未授权修改;0090 授权的是防守性/自有/主动修改。

## 风险熔断

若后续司法实践或监管政策变化导致本 ADR 授权范围不再合规:
- 立即停止 T4/X14 功能分发
- 已加固 APK 不受影响(本地运行,无远程 kill)
- 回退方案:T4 降级为玄甲 X1 路径(SDK 自身字符串加密,不碰用户 DEX)
